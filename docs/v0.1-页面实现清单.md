## 2. 首页（托管）

### 空闲态

| 卡片 | 内容 | 真实来源 |
|---|---|---|
| 状态卡 | 体力 / 清洁 / 心情 三项读数 + 状态胶囊 | `PetManagedRuntime.state` 的 `ObservedValue` |
| 上次运行 | 已完成节数、护理次数、分钟数、开始时间、截图张数 | `run-record.json` + 截图目录 |
| 本次方案 | 日常维持（已启用）、收益行动（暂未开放） | 静态能力声明 |
| 开课阈值 | 90 / 90，及低于阈值时的行为说明 | 从 `PetStudyHealthPolicy` 反推 |
| 底部主控 | 单批 1/2/3 节选择、`开始托管`、两行预算提示 | `DailyBudgetStore`（480 分钟硬上限） |

### 运行态

| 卡片 | 内容 | 真实来源 |
|---|---|---|
| 当前任务 | 流程名 + 第 N 节/共 M 节、当前步骤、进度条与百分比 | `PetManagedRuntime.state` |
| 运行截图 | 最近 4 张实拍，标注"共 N 张 · 仅本地" | 会话目录下的 PNG |
| 运行日志 | 最近 6 条已翻译事件 | `files/pet_mvp.log` |
| 底部主控 | `暂停`（说明性弹窗）、`停止托管`（二次确认） | 见 §5 |

### 状态呈现规则（诚实性契约）

三项读数按 `ObservedValue` 的四种状态如实呈现，**不允许把未知画成正常**：

| 状态 | 显示 | 副标题 |
|---|---|---|
| `Known`（本会话） | `≈96` | `22:42 确认` |
| `Known`（非本会话） | `≈96` | `上次 22:42` |
| `Unknown` | `—` | `未确认` |
| `Stale` | `≈<上次值>` | `已过期 · 22:44`（琥珀色） |
| `Unsupported` | `—` | `不支持` |

新鲜度窗口 60 秒。**运行期间读数会自然过期**：一节课约 10 分钟，中途不重复读取健康页，因此运行中后期看到"已过期"是真实行为，不是 bug。

## 3. 记录

| 卡片 | 内容 | 真实来源 |
|---|---|---|
| 今天 | 时间区间、总分钟数、学习节 / 护理次 / 暂停次 | 当日全部 `run-record.json` |
| 已确认的状态变化 | 最多 3 张实拍缩略图 + 体力/清洁/心情 首节→末节 与增减 | `round-N.json` 的 before/after |
| 动作与道具 | 喂食小饼干、洗澡、鼓励 ×N、剩余库存 | 见下方判定规则 |
| 暂不支持读取 | 力量 / 智力 / 魅力、金币与收益、背包库存数量、成绩等级 | `ObservedValue.Unsupported` |
| 历史运行 | 每条会话的时间、结果、明细、截图数 | 会话目录扫描 |

**动作生效判定**：`发出 ≠ 生效`。喂食/洗澡只有在后续读数确实回升时才标"生效"，否则标"待确认"；鼓励一律"待确认"（游戏是否计入无法确认）；库存为"未知"（游戏未提供可稳定识别的位置）。

## 4. 设置

统一入口，只呈现**有真实数据源**的项目。

| 分组 | 行 | 真实来源 |
|---|---|---|
| 权限与环境 | Shizuku 权限、虚拟屏（display id / 分辨率 / dpi）、通知 | `ShizukuState`、`IDisplayRepository`、`NotificationManagerCompat` |

## 5. 暂停 / 恢复：为什么按钮不可操作

`PetAutomationService` 只暴露 `START` 与 `STOP` 两个 action，**没有手动暂停/恢复 API**。`PAUSED` / `RESUMING` 只由业务层的 `SessionRecovery` 在检测到异常（锁屏、虚拟屏失效、页面无法确认）时自动产生。

因此：
- 首页 `暂停` 按钮**不伪造暂停**，点击后弹出说明："手动暂停暂未开放"，并解释自动暂停规则（120 秒内最多尝试恢复 3 次、期间不发送任何输入、恢复失败则安全停止），同时给出真实替代动作 `改为停止托管`。
- 自动暂停真正发生时，`CurrentTaskCard` 会显示 `已暂停`/`恢复中` 胶囊与 `PausedBanner`。
- 参考图中"检查并继续 / 继续后会做什么"的整屏不可复刻为可操作界面，因为它需要手动恢复 API。

## 6. 本轮修复的真实缺陷

| 缺陷 | 影响 | 修复 |
|---|---|---|
| `PetFootButton` 从未应用 `onClick` | **全部主控按钮失效**：开始托管、停止托管、返回托管、校准截图都点不动。截图完全看不出来 | `PetUiKit.kt` 补 `.clickable(enabled, onClick)`；DISABLED 真正吞掉点击 |
| 设置页"虚拟屏"行有 chevron 但无点击 | 暗示可点却无响应 | 包 `clickable { onOpenConsole() }` |
| 当前任务卡主标题直接打印引擎 token（`RECOVER_IF_NEEDED`、`WAIT_HIGH_FIVE_WINDOW`） | 内部标识符泄漏给用户 | 新增 `stepHeroText()` 翻译，未知 token 降级为"正在执行本步骤" |
| 运行日志被 400 条重复"学习画面已确认"淹没 | 出问题时最需要看的页面不可读 | `collapseRepeats()` 折叠连续重复并显示 `×N` |
| 首页底部提示两行挤在一行 | 读起来像一句断句 | 改为两行堆叠 |
| 首页滚动内容透到 footer 下方 | 方案卡文字与节数选择器视觉重叠 | footer 加不透明背景 |
| 首页截图说明与记录页不一致 | 同一文件两种标签 | 统一用 `RecordsPresentation.frameCaption` |
